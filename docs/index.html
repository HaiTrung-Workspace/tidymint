Good to know

What is “System Data” on a Mac?

In System Settings › General › Storage, macOS groups everything it cannot sort into a category called System Data. It often grows to tens of gigabytes and is hard to inspect from Finder.

  • App and browser caches, logs and temporary files
  • Leftovers from apps you already deleted
  • Local Time Machine snapshots and old installers
  • For AI work: model weights and package caches

Tidymint shows which of these folders are large on your Mac, explains each one in plain words, and lets you move the safe ones to the Trash.

Questions

Is Tidymint really free?

Yes. It is open source under the MIT licence, with no account, no subscription and no paid tier.

Is it safe?

Tidymint only moves items to the Trash, so you can put anything back. It never touches Photos, Mail, keychains, cloud storage roots or Apple system caches, and risky items are never pre-selected.

Why does macOS block it the first time?

Tidymint is not notarized by Apple yet (that needs a paid developer account). Open it once from System Settings › Privacy & Security › Open Anyway, as Apple describes in its own guide. The source code is public on GitHub.

Does it send my data anywhere?

No. It works offline. Data only leaves your Mac if you send feedback or join the newsletter yourself.

How is it different from CleanMyMac?

Tidymint is free and open source and focuses on cleaning and disk space. It has no scanner of its own and relies on the protection built into macOS (XProtect, Gatekeeper); CleanMyMac bundles its own and charges a subscription.

Where do I download it safely?

Only from tidymint.app or the GitHub releases page. Tidymint has no other website, no app store listing and no paid version. Anything else is not us.

Which Macs are supported?

macOS 14 or later, on both Apple silicon and Intel.

Is there a Windows or iPhone version?

No. iOS does not allow apps to clean other apps' data, and Windows is not planned for now.

Install

macOS 14 or later, Apple silicon and Intel.

Tidymint is not notarized by Apple yet, so macOS blocks the first launch. This happens to every app that is not notarized. The source code is public on GitHub.
  1. Download Tidymint.zip, open it and drag Tidymint to Applications.
  2. First launch: double-click Tidymint. When macOS says it cannot be opened, click Done.
  3. Allow it: open System Settings › Privacy & Security, scroll down, click Open Anyway, enter your password if asked, then Open.
  4. Full Disk Access: in the same pane, turn on Tidymint under Full Disk Access so it can measure every folder.

Steps from Apple: Safely open apps on your Mac. Source code and build steps are on GitHub.
