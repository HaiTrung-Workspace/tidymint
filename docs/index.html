Good to know

What is “System Data” on a Mac?

In System Settings › General › Storage, macOS groups everything it cannot sort into a category called System Data. It often grows to tens of gigabytes and is hard to inspect from Finder.

  • App and browser caches, logs and temporary files
  • Leftovers from apps you already deleted
  • Local Time Machine snapshots and old installers
  • For AI work: model weights and package caches

Tidymint shows which of these are big on your Mac and moves safe caches, logs and app leftovers to the Trash. Time Machine snapshots are left to macOS, which removes them when space runs low.

FAQ

Before you download

Is Tidymint really free?

Yes. It is open source under the MIT licence, with no account, no subscription and no paid tier.

Is it safe?

Tidymint only moves items to the Trash and Undo puts the last clean back. Photos, Mail, keychains, cloud folders and Apple system caches are never touched.

Where do I download it safely?

Only from tidymint.app or the GitHub releases page. Tidymint has no other website, no app store listing and no paid version. Anything else is not us.

Why does macOS block it the first time?

Tidymint is not notarized by Apple yet (that needs a paid developer account). Open it once via System Settings › Privacy & Security › Open Anyway. The source is public on GitHub.

Does it send my data anywhere?

No. The only network call is a once-a-day check for a new version, which reads a version number and sends nothing about your Mac. Data leaves your Mac only when you send feedback yourself.

How does the duplicate check protect my projects?

Add your project folders once in Settings. Before deleting duplicates, Tidymint searches those folders: any file still named in a script or skill is flagged in red and unticked. Without project folders the app reminds you first.

How is it different from CleanMyMac?

Tidymint is free and open source and focuses on cleaning and disk space. It has no scanner of its own and relies on the protection built into macOS (XProtect, Gatekeeper); CleanMyMac bundles its own and charges a subscription.

Does it have a “free up RAM” button?

No. macOS manages memory on its own, and forcing it empty tends to make a Mac slower, not faster. If you turn it on, the menu bar icon simply tells you when more than 90% of memory is in use.

Which Macs are supported?

macOS 14 or later, on both Apple silicon and Intel.

Is there a Windows or iPhone version?

A Windows version is in development, no release date yet. iPhone: no, iOS does not let apps clean other apps' data.

Install

macOS 14 or later, Apple silicon and Intel.

Tidymint is not notarized by Apple yet, so macOS blocks the first launch, like any app without notarization. Sponsoring the project pays for the Apple Developer account: then the app just opens and updates arrive faster.

Steps from Apple: Safely open apps on your Mac. Source code and build steps are on GitHub.

  1. 1

    Download

    Click Download Tidymint, open Tidymint.zip in Downloads and drag Tidymint to Applications.

  2. 2

    First launch

    Double-click Tidymint. When macOS says it cannot be opened, click Done. Do not choose Move to Trash.

  3. 3

    Allow it

    Open System Settings › Privacy & Security, scroll to the Security heading and click Open Anyway, then confirm with your password. Step-by-step guide with screenshots.

  4. 4

    Full Disk Access optional

    In Privacy & Security, open Full Disk Access and turn on Tidymint, so Mail, Messages and Library are measured too. How.
