Sponsor Tidymint

Tidymint is free and will stay free. Sponsoring is optional and unlocks nothing extra.

Not open for sponsorship yet

Our GitHub Sponsors account is waiting for approval. Once it is approved, the sponsor button will appear right here. Until then, you can still help in the ways below.

Where the money goes

  • The Apple Developer account, $99 a year. With it, Apple verifies the app: new users download it and it just opens, no trip to Settings > Security.
  • Faster updates. A verified app can update itself, so you no longer download each new version by hand.
  • Anything left over pays for the tidymint.app domain and time spent on new versions.

Ways to help that cost nothing

  • Star it on GitHub. Stars help strangers trust the app the first time they see it.
  • Report a bug or suggest something. Open an issue on GitHub, or use Contact inside the app.
  • Send it to someone who needs it. One friend complaining about a full Mac is enough.
  • Suggest an app to clean. Open an issue on GitHub with the app name and the folder that takes up space. Tidymint measures it on a real Mac before adding it.
