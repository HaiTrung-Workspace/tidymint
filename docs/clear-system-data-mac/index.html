How to clear System Data on Mac, safely

Updated: October 26, 2026 · 8 min read

Quick answer

System Data is macOS's catch-all bucket for files that don't fit another category: caches, logs, local Time Machine snapshots, old iPhone backups, developer tools and more. You can shrink it safely by restarting, emptying the Trash, deleting local snapshots, clearing user caches, removing old device backups and cleaning Xcode, Docker or AI model caches. Never delete anything inside /System or /private/var.

What is System Data?

Apple describes System Data (called "Other" on older macOS) as a general category that measures storage used by Apple and third-party files that don't fit a more specific category. In practice, it usually includes:

  • App and browser caches, logs and temporary files
  • Local Time Machine snapshots stored on your internal drive
  • Old iPhone and iPad backups
  • Developer files: Xcode build data, simulators, Docker disk images
  • For AI work: downloaded model files and package caches
  • Files macOS needs to run, like virtual memory and the sleep image (leave these alone)

On a Mac that has been in use for a year or two, System Data can grow to 50 GB or more, and macOS gives you no button to clear it.

Check how big it is

Open Apple menu › System Settings › General › Storage (macOS 13 Ventura or later). Wait for the bar to finish calculating, then hover over the gray segment to see the System Data size. Note the number so you can see what each step frees.

7 safe ways to shrink System Data

1. Restart your Mac

A restart clears temporary files and swap. It is free, safe, and sometimes frees several gigabytes on its own.

2. Empty the Trash and your Downloads folder

Files in the Trash still take space until you empty it. Old installers (.dmg, .pkg, .zip) in Downloads are a common hidden cost.

3. Delete local Time Machine snapshots

If you use Time Machine, macOS keeps snapshots on your internal drive. macOS removes them when it needs space, but the Storage screen often counts them as System Data. To list and remove them, open Terminal:

tmutil listlocalsnapshots /
sudo tmutil deletelocalsnapshots 2026-10-20-101500

Replace the date with one from the list. Your backups on the external Time Machine drive are not affected.

4. Clear user caches

Quit your apps, then in Finder press Shift+Cmd+G and go to ~/Library/Caches. Move the folders of apps you recognize to the Trash. Apps rebuild what they need, so the first launch afterward may be a little slower.

Use ~/Library/Caches (with the tilde, your own folder), not /Library/Caches or /System/Library/Caches.

5. Remove old iPhone and iPad backups

Open System Settings › General › Storage and click the info button next to iOS Files. Delete backups of devices you no longer own or no longer need.

6. Clean developer leftovers

  • Xcode build data: move ~/Library/Developer/Xcode/DerivedData to the Trash. Xcode recreates it.
  • Old simulators: run xcrun simctl delete unavailable.
  • Docker: run docker system prune to remove unused images and containers.
  • node_modules in old projects you no longer work on.

7. Clean AI model caches

  • Ollama: run ollama list, then ollama rm model-name for models you don't use.
  • Hugging Face: downloaded models live in ~/.cache/huggingface.

A single local model can be several gigabytes, so this is often the biggest win on an AI workstation.

What you should never delete

  • Anything inside /System, /private/var/vm (virtual memory) or /private/var/db
  • The whole ~/Library folder, or your Photos and Mail libraries
  • Files you don't recognize. If you are not sure, leave it.

Also be careful with "one click" cleaners that delete permanently. If something goes wrong, there is no undo.

FAQ

Is it safe to delete System Data on Mac?

Parts of it, yes: caches, old downloads, local Time Machine snapshots, old device backups and developer build data are safe to remove. Files macOS needs to run, such as virtual memory, are not. Never delete anything inside /System or /private/var.

Why is my System Data so large?

The usual causes are local Time Machine snapshots, app and browser caches, old iPhone backups, Xcode and Docker data, and downloaded AI models. On developer and AI machines it can pass 100 GB.

Will System Data shrink on its own?

Partly. macOS removes local snapshots and some caches when space runs low, and a restart clears temporary files. It will not remove developer files, models or old backups for you.

Does restarting clear System Data?

It clears temporary files and swap, which can free a few gigabytes. Larger items like snapshots and caches need the other steps.
